# Product Overview

Phoenix Events Recommender is a personal event aggregator for the Phoenix Valley, AZ area that uses LLM-based preference learning to recommend events.

## Core Features

- Automated event scraping from multiple Phoenix Valley sources (Eventbrite, Phoenix.gov, local venues)
- SQLite database storage for events and user feedback
- Web interface for browsing and filtering events by source
- LLM-powered recommendation system that learns from user feedback (interested/not interested)
- Events ranked by relevance to user preferences

## Target Users

Individual users in the Phoenix Valley area looking for personalized event recommendations based on their interests.

## Key Value Proposition

Aggregates events from multiple sources (both major platforms and local venues) and learns user preferences over time to surface the most relevant events, eliminating the need to check multiple websites manually.
